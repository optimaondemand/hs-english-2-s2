Publishing a Finished Document
Literature · Week 9
📖 TODAY’S FOCUS
A published document works for a reader who has never met its author.
Consistent structure, captioned and credited images, alt text, a fixed-layout export, and a link that opens are the difference between a draft and a finished document. The steps below apply in Word or PowerPoint.
🎯 OBJECTIVES
1
I can apply heading styles, margins, and a consistent layout to a finished document.
2
I can place an image with a caption, a credit line, and alt text.
3
I can export a document to PDF and share it by link from OneDrive.
📚 PART 1 · WHAT PUBLICATION-READY MEANS
⚡ QUICK CHECK-IN
Which part of a page does a reader notice before reading any text?

What publication-ready means

A document is publication-ready when a stranger can open it, read it, and move through it without the author present. Four conditions hold: the structure is consistent, every image is labeled and credited, the document is accessible, and the final file is fixed in layout so that it looks the same on any device.

Structure

1
Apply heading styles, not manual bold.
In Word, use Home, then Styles, then Heading 1 or Heading 2. In PowerPoint, use the slide layout’s title box. Styles let a reader navigate and keep headings consistent.
2
Set margins and spacing once.
Use the Layout tab for margins. Keep body text at a standard readable size, with a line of space between paragraphs.
3
Limit the document to two typefaces.
One for headings and one for body text. Change a typeface through the style, so every heading changes at once.
4
Add page numbers.
A reader who prints the document or cites a page needs them.
📚 PART 2 · IMAGES WITH CAPTIONS, CREDITS, AND ALT TEXT

An image does three jobs on a page: it shows, it is labeled, and it is credited. A reader who uses a screen reader cannot see it and depends on alt text. Each image gets all four items.

HEADING STYLE
Applied from the Styles gallery, not set by hand.
IMAGE
Placed in line with the text, sized inside the margins.
CAPTION
A figure number and a short description.
CREDIT LINE
Who made the image and, for a source work, where it was found and under what terms.
ALT TEXT (NOT VISIBLE)
“Pencil sketch of a wood set: branches overhead, a lantern on a post.”
1
Place the image in line with the text.
Right-click the picture, choose Wrap Text, then In Line with Text, so it stays with its paragraph.
2
Add a caption.
In Word, References, then Insert Caption. The caption holds a figure number and one sentence.
3
Add a credit line.
Name the maker. For a source work, add the museum or archive, and its terms of use (for example, public domain).
4
Add alt text.
Right-click the picture and choose View Alt Text. Describe what the image shows in one sentence, without “image of”.
🤖 AI AWARENESS
AI image tools can produce concept images quickly. They cannot say whose work an image imitates, and a generated image does not come with a credit to a source. A caption labels an AI-generated image as AI-generated, names the tool, and says what was changed. AI-drafted alt text must be checked against the image, because it can describe objects that are not there.
📚 PART 3 · EXPORT AND SHARE

Export fixes the layout. A word-processing file reflows when opened on a different device or version; a PDF does not. Exporting takes a few steps.

1
Check the document first.
In Word, Review, then Check Accessibility. In PowerPoint, Review, then Check Accessibility. Fix the items it flags, such as missing alt text.
2
Export to PDF.
File, then Export, then Create PDF. Or Save As and choose PDF. Menu names vary a little by version.
3
Open the PDF and read it through.
Look for images that moved, headings stranded at the bottom of a page, and links that do not work.
4
Share by link from OneDrive.
Upload the PDF to OneDrive, choose Share, set who can view, and copy the link.
5
Test the link.
Open it in a private browser window. If it asks for a login, the sharing setting is wrong.

PowerPoint follows the same steps. Its layout adds three points: one idea per slide, large type, and alt text on every image. A deck exported to PDF becomes a document, and each slide becomes a page.

2. Which caption includes what a reader needs for an AI-generated image?
3. Which file format keeps a finished document’s layout fixed on any device?
4. A shared link opens for the author but asks a classmate to sign in. What should the author do?
🔑 KEY TERMS
▶
Alt text: a short description of an image for readers who cannot see it.
▶
Credit line: the maker of an image and, for a source work, its source and terms of use.
▶
Export: saving a finished file in a fixed-layout format such as PDF.
